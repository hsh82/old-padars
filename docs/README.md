# Padars School TMS

This documentation records the verified architecture and implementation status for the Padars MVP on Frappe 16/Education 16.

## Status convention

- **Confirmed**: observed in the checked-out source or verified by an executed command.
- **Implemented**: present in Padars source and covered by executed tests.
- **Proposed**: designed but not yet implemented or externally verified.
- **Blocked**: requires an unavailable dependency, environment, or product decision.
